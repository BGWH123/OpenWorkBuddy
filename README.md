# OpenWorkBuddy

OpenWorkBuddy 是一个在本机运行的 AI 工作台。选定一个文件夹后，可以用自然语言布置任务，让它在这个文件夹里阅读、整理和生成文件，并在右侧查看产物和变更。

使用方式参考了 WorkBuddy 的公开说明：任务列表、默认 / 计划 / 仅问答、对话，以及产物、文件和变更。程序、界面和提示都是独立编写的，不包含 WorkBuddy 的安装包、界面资源或在线服务。

## 功能

- 桌面窗口直接打开，不用自己在浏览器里输入地址
- 三种模式：默认执行、先出方案再确认、只读问答
- 在工作区里读取、搜索、写入文件，并执行命令
- 把文件或整个文件夹拖进窗口，作为任务附件
- 右侧查看产物、工作区文件、变更、浏览器和终端
- 专家和技能使用本地 Markdown，可以按自己的工作方式补充

## 启动

需要 Node.js 20 或更新版本。

```bat
npm install
npm run build
npm start
```

Windows 上也可以双击 `启动.bat`。

关掉窗口后，这次启动的服务会一起退出。服务只监听本机 `127.0.0.1`。

## 模型

没有填写外部接口时，程序用本地规则完成明确的文件任务，例如建文件、列目录、搜索和整理。

设置里可以改成 OpenAI 兼容接口，并选择模型。接口地址和密钥只写在本机 `data/state.json`。这个文件已从仓库中排除，设置接口也不会把密钥返回给界面。

## 工作区约定

- 相对路径限制在当前工作区里
- 需要写到工作区以外时，把目录加到设置中的额外目录
- 自己的专家放在工作区 `.openworkbuddy/experts`
- 自己的技能放在工作区 `.openworkbuddy/skills/<名称>/SKILL.md`

## 测试

```bat
npm test
npm run verify
```

`npm run verify` 会用本机 Edge 走一遍打开工作区、默认执行、计划确认和仅问答。

## 说明

仓库里不包含本机任务记录、上传的资料、窗口缓存或模型密钥。克隆之后需要自己在设置里填写接口。
